# 世界杯彩票盈利系统

基于统计均值回归的 2026 世界杯投注工具。双窗口统计 + 多维度信号 + 等利润动态注额。

## 快速开始

```bash
pip install fastapi uvicorn sqlalchemy beautifulsoup4 playwright
python main.py
```

浏览器打开 `http://localhost:8000`。

## 页面功能

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `/` | 导航入口 |
| 手动投注 | `/manual` | 比赛管理、赔率录入（SPF/总进球/比分）、下注、赛果结算 |
| 智能分析 | `/smart` | 双窗口统计、多维度均值回归分析、下注方向推荐 |

智能分析和手动投注共享同一数据库。智能分析提供推荐方向，实际下注在手动投注页面完成。

## 策略：合并均值回归

### 核心设计

- **双窗口**：全赛累计 + 12 场滚动，各窗口独立统计
- **历史基线**：2006-2022 小组赛 192 场数据
- **观察期**：前 12 场仅统计不下注，第 13 场起输出推荐
- **等利润注额**：Stake = 100 / (Odds - 1)，带安全上下限
- **非对称**：仅在高偏离方向出手（偏高 → 均值回归）

### 三个维度

#### SPF（胜平负）

| 子维度 | 基线 | 触发逻辑 |
|--------|------|----------|
| 冷门率 | 18.0% | 偏高 → 押热门回归 |
| 平局率 | 21.9% | 偏高 → 押分胜负 |

#### 总进球数（6 桶：0~5+）

某进球数超标 → 找最欠代表的进球数 → 押它回归。阈值分层：

- **Tier A**（基线 ≥10%）：强信号 +61%
- **Tier B**（基线 5-10%）：强信号 +100%

#### 比分（8 个 Tier A+B）

与进球逻辑相同。额外要求至少出现 3 次才触发，避免 12 场小样本误报。

### 信号合并

双窗口取交集：双强或一强一弱 → 触发；双弱/单一信号 → 忽略。

### 注额参数

| 参数 | 值 |
|------|-----|
| 小组赛预算 | ¥3,000 |
| 目标盈利/注 | ¥100 |
| SPF 单注上限 | 5%（¥150） |
| 进球/比分单注上限 | 2%（¥60） |
| 单注下限 | 0.1%（¥3） |

SPF 使用更高上限，因为热门低赔率（1.3-1.8）需更大注额才能接近目标利润。

## 手动投注使用流程

1. **添加比赛**：在左侧输入日期、阶段、主客队
2. **录入赔率**：点击"赔率"按钮填写 SPF + 总进球（0~7+）+ 比分赔率，或点击"刷新赔率"从 500.com 自动抓取
3. **下注**：选择比赛 → 选择维度（胜平负/进球数/比分）→ 选方向 → 填金额 → 确认
4. **结算**：赛后点击"赛果"录入比分，系统自动结算盈亏

## 智能分析使用流程

1. 先在手动投注页面录入已结束比赛的赛果和赔率
2. 进入智能分析页面，选择即将开始的比赛
3. 填入 SPF 赔率（可展开填写总进球和比分赔率）
4. 点击"分析"，系统输出各维度推荐方向
5. 到手动投注页面按推荐方向下注

## API 端点

### 手动投注
- `GET/POST /api/manual/matches` — 比赛 CRUD
- `GET/PUT /api/manual/matches/{id}` — 单场比赛详情 / 更新赔率
- `PUT /api/manual/matches/{id}/score` — 录入赛果 + 自动结算
- `GET/POST/DELETE /api/manual/bets` — 投注管理
- `GET/PUT /api/manual/bankroll` — 资金管理

### 智能分析
- `GET /api/smart/context` — 当前双窗口统计
- `POST /api/smart/recommend` — 获取策略推荐

### 赔率
- `POST /api/odds/refresh` — 从 500.com 抓取 SPF + 总进球 + 比分赔率

## 赔率爬虫

支持竞彩三种玩法：

- **SPF（胜平负）**：urllib 直抓，快
- **总进球数（0~7+）**：Playwright 渲染，8 个选项，5/6/7+ 自动取平均供策略使用
- **比分（31 个）**：Playwright 渲染

ZJQ 抓取失败自动重试 3 次。

## 技术栈

- **后端**：FastAPI + SQLAlchemy + SQLite
- **前端**：原生 HTML/JS
- **爬虫**：urllib + BeautifulSoup + Playwright
- **数据**：竞彩实时赔率（500.com）+ 2006-2022 历史基线
