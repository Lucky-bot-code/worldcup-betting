# 世界杯彩票盈利系统

基于统计均值回归的2026世界杯投注系统。包含历史回测、手动投注跟踪和实时智能推荐。

## 快速开始

```bash
pip install fastapi uvicorn sqlalchemy
python main.py
```

浏览器打开 `http://localhost:8000`。

## 页面功能

| 页面 | 路径 | 说明 |
|------|------|------|
| 回测系统 | `/` | 9种策略在2014-2022历史数据上回测 |
| 手动投注 | `/manual` | 创建比赛、输入赔率、下注（胜平负/总进球数/比分） |
| 智能下注 | `/smart` | 根据已结算赛果+策略模型，推荐下注方向 |

## 策略体系

### 主力策略（推荐用于2026世界杯）

| 策略 | 回测收益 | 说明 |
|------|----------|------|
| **五信号动态统计** | +7.77% | 12场滚动窗口，五级阈值，仅在爆冷率/平局率偏高时押热门回归 |
| **锦标赛动量** | +12.77% | 前8场观察定方向，锁定后整届单向押注均值回归 |

### 基准策略（回测对比用）

买强队、凯利公式、深盘强队、平局猎人、淘汰赛下盘、赔率区间、价值投注

## 五信号策略详解

每场比赛统计12场小组赛滚动窗口中的5个维度：

| 信号 | 指标 | 历史均值 | 触发规则 |
|------|------|----------|----------|
| 爆冷率 | 赔率差≥2倍时弱队胜出 | 18% | >P75(25%)弱押热门，>P90(29%)强押热门 |
| 小球率 | 总进球<3 | 48% | 辅助参考（无对应盘口） |
| 平局率 | 双方打平 | 20% | >P75(25%)押分胜负，>P90(33%)强押 |
| 进球分布 | 0~5+球概率分布 | — | 0球率>15%时增强热门信心 |
| 比分概率 | ≤3球各比分概率 | — | 辅助调整置信度 |

**非对称设计**：仅在高偏离方向出手（偏高→均值回归），低偏离不下注。押冷门方向在历史回测中持续亏损。

## 锦标赛动量策略详解

1. **观察期**（前8场小组赛）：统计冷门率（赔率差≥2.5倍且热门输球）和平局率
2. **定方向**（8场后一次性判断）：
   - 冷门率 > 42%+10% → 冷门潮，押热门回归
   - 冷门率 < 42%-10% → 过于平静，押下盘爆破
   - 平局率 > 22%+13% → 平局太多，押分胜负
   - 正常范围 → 整届观望
3. **执行**：方向锁定后一直押到小组赛结束

与五信号的关键区别：动量是锦标赛级别的一次性判断，五信号是每场独立的滚动窗口判断。

## API 端点

### 回测
- `POST /api/backtest/run` — 运行回测
- `GET /api/backtest/bets?run_id=` — 查看下注记录
- `GET /api/strategies` — 策略列表

### 手动投注
- `GET/POST /api/manual/matches` — 比赛管理
- `PUT /api/manual/matches/{id}/score` — 录入赛果+自动结算
- `GET/POST /api/manual/bets` — 投注管理
- `GET /api/manual/bankroll` — 资金状态

### 智能下注
- `GET /api/smart/context` — 当前统计窗口
- `POST /api/smart/recommend` — 获取策略推荐

## 手动投注使用流程

1. 在页面左侧添加比赛（或使用预导入的2026世界杯赛程）
2. 在右侧选择比赛，切换胜平负/总进球数/比分tab，填入赔率和方向
3. 比赛结束后，点击"赛果"按钮录入比分（可选填赛前SPF赔率供智能分析）
4. 系统自动结算盈亏，更新资金

## 智能下注使用流程

1. 先在手动投注页面录入已结束比赛的赛果+赛前SPF赔率（关键步骤）
2. 进入智能下注页面，选择一场即将开始的比赛
3. 填入当前赔率，点击"分析"
4. 五信号和动量策略各给出推荐（或观望），用户据此到手动投注页面下注

由于服务器无法直接访问 GitHub，使用 SCP 同步：

```bash

```

同步脚本会：
1. 上传所有 .py / .html / .txt / .yaml / .sh 文件
2. 安装新的 Python 依赖（如有）
3. 重启 worldcup 服务
